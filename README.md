# The Rice Group — Temporary Landing Page

This repository contains the temporary landing page for The Rice Group at Compass.

The page provides an interim web presence until a reworked site can be created. It is a placeholder for the future website.

## Repository contents

- `index.html` — the current landing page.
- `images/` — site images and assets.
- `CNAME` — custom domain configuration.

## Preview locally

Open `index.html` in a web browser to view the landing page.
